One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun. The program writes the pitch
to `/output/entry.txt` — nothing else, no code, no explanation.

> Just describe the app you've been picturing in your head to an AI on
> make.fun, watch it appear on your screen in minutes, and if you don't
> love it you've lost nothing — you never wrote a line of code.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
